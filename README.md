# 🚀 NASA APOD Explorer

A modern astronomy image explorer built with **Next.js**, **React**, and **TypeScript** that allows users to discover NASA's Astronomy Picture of the Day, explore historical space imagery, save favorites, and enjoy an immersive space-themed experience.

---

## Live Demo

🔗 https://nasa-apod-explorer-nu.vercel.app/

---

## Features

- NASA APOD API Integration
- Search Images by Date Range
- Favorites Management with Local Storage
- Interactive Image Preview Modal
- Fully Responsive Design
- Modern Glassmorphism UI
- Fast Performance with Next.js
- Space-Themed User Interface
- Live Deployment on Vercel

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/yourusername/nasa-apod-explorer.git
```

### Navigate to Project

```bash
cd nasa-apod-explorer
```

### Install Dependencies

```bash
npm install
```

### Create Environment Variable

Create a file named:

```env
.env.local
```

Add:

```env
NEXT_PUBLIC_NASA_API_KEY=YOUR_NASA_API_KEY
```

### Start Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
